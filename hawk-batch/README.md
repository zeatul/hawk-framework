# hawk-batch

[English](#) | [中文](README_zh.md)

Batch processing framework module (planned).

## Status
🚧 **In development** — currently it only depends on hawk-core; the core functionality is yet to be implemented.

## Planned Features
- [ ] Batch task scheduling and execution
- [ ] Chunk-oriented read/process/write
- [ ] Retry, skip, and listener mechanisms
- [ ] Multi-threaded / distributed execution support
- [ ] Spring Batch compatibility adapter layer

## Dependencies
- hawk-core

## Quick Start
```gradle
implementation "io.github.zeatul:hawk-batch:1.3.0-SNAPSHOT"
```

> ⚠️ The current version is not production-ready; wait for a future release.
